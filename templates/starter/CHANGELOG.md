# Changelog

## TCN 0.2.0 — 2026-11-10

- Implement screens directly in route pages and group feature code by responsibility, with shared Gallery/Tweak demos.
- Add AGENTS.md conventions and guides for feature development, global/shared ownership and removing starter examples.
- Add the complete typed Nerd Fonts catalog and `/gallery/icons` for finding, previewing and copying icons.
- Preserve legacy icon names and support installing individual icon sets through TCN.

## TCN 0.1.2 — 2026-11-10

- Stabilize auto-sized popup dimensions and placement before display while preserving immediate backdrop dimming and focus restoration.

## TCN 0.1.1 — 2026-11-09

- Move theme palettes and component defaults into `src/lib/ui/styles.ts`, replacing per-component style files.

## 0.1.0 — 2026-11-09

- Provide a React/OpenTUI application with generated filesystem routing, strict TypeScript and Biome.
- Include 51 component families with local source, light/dark themes and shared focus, keyboard and overlay behavior.
- Add Home, Gallery, composed Showcase and Tweak preview screens.
- Support content-driven popup sizing with minimum/maximum bounds and keyboard-visible scrolling.
- Include native Bar/Line charts, code display, conversation layouts, notifications, forms and resizable navigation.
- Save local Tweak drafts and export design proposals for applying changes to component source.
- Include component, router, interaction, styling and development-tool tests.
